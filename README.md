# IT без паники

Учебный сайт на русском с адаптацией под телефон. 12 подробных уроков, бытовые аналогии, технические примеры, 24 вопроса самопроверки, 18 вопросов для интервью, словарь и локальный тренажёр HTTP.

## Запуск двойным щелчком

Открой **START.bat**. Он запустит сервер и откроет сайт в браузере по адресу **http://localhost:4173**. Если порт занят, автоматически выберется следующий — точный адрес будет написан в окне. Чтобы остановить сервер, закрой это окно или нажми Ctrl+C.

Нужен **Node.js 18+ или Python 3**. На компьютере, где готовился проект, оба уже установлены. BAT сначала пробует Node.js, затем Python. Никаких библиотек, ключей и npm install для локального запуска не требуется. Не открывай index.html двойным щелчком — используй START.bat для стабильного сохранения прогресса.

Вручную, если удобнее: `npm start` либо `python server.py --open` из папки проекта.

## Размещение на Vercel

1. Загрузи **содержимое этой папки проекта** в свой репозиторий GitHub / GitLab / Bitbucket. Файлы `package.json`, `vercel.json`, `index.html` должны лежать в корне проекта. Другие личные папки загружать не нужно.
2. В Vercel выбери **Add New → Project**, импортируй репозиторий.
3. **Root Directory**: `./`, если репозиторий содержит только этот проект. Если он лежит внутри большой папки, выбери путь к папке проекта.
4. **Framework Preset**: Other. **Build Command**: `npm run build`. **Output Directory**: `dist`. Эти настройки уже записаны в `vercel.json`.
5. Нажми **Deploy**. Переменные окружения, база данных и внешнее API не нужны.

Прямые ссылки на уроки используют хеш, например `/#lesson/methods`, и работают без настройки серверных перенаправлений.

Сайт подготовлен для Vercel, но в аккаунт пользователя не публиковался. Папка `dist` содержит готовые статические файлы; при сборке Vercel создаст её заново. Если устанавливаешь Vercel CLI самостоятельно, из папки проекта также можно выполнить `vercel` и пройти авторизацию.

Документация: [настройки сборки Vercel](https://vercel.com/docs/builds/configure-a-build).

## Что внутри

- Вечер 1: интернет, клиент-сервер, протоколы, запрос, методы, URL.
- Вечер 2: заголовки, тело и JSON, ответы, системный аналитик, сравнение ролей, сквозной пример.
- Тренажёр: GET / POST / PUT / PATCH / DELETE, JSON, query, заголовки, изменение учебных заказов, ошибки 400 / 404 / 405 / 406 / 415 / 422.
- Словарь, поиск по всему курсу, увеличение текста, печать урока и шпаргалки.
- Прогресс и ответы сохраняются в localStorage текущего браузера. Они не синхронизируются между устройствами и разными адресами сайта. Режим инкогнито / очистка данных удаляет их.
- Модель кафе работает в памяти вкладки, не делает реальных HTTP-запросов и сбрасывается при перезагрузке. Все примеры вымышлены.

## Файлы и изменение материалов

- `course.js` — уроки, тесты, словарь и ответы для интервью.
- `app.js` — страницы, навигация и взаимодействие.
- `lab.js` — логика локального API-тренажёра.
- `styles.css` — внешний вид, мобильная версия и печать.
- `START.bat`, `server.cjs`, `server.py` — локальный запуск.
- `vercel.json` — настройки Vercel.

Материалы и графика находятся в проекте, внешних шрифтов и CDN-зависимостей нет. Для перехода к первоисточникам потребуется интернет.

## Проверки

`npm run check` проверяет синтаксис и полноту курса. `npm test` проверяет поведение тренажёра. `npm run build` создаёт готовую папку `dist`.

Технические определения сверялись с MDN и стандартами IETF, рамки ролей — с IIBA и SFIA. Ссылки есть в уроках и на странице «Источники и о курсе».
